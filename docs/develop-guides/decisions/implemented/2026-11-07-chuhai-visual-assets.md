# 链证出海视觉素材统一

状态：implemented
类型：feature
Owner：web/src/config/brand.js

## 问题

外部随机头像和不同风格的文件图标影响产品视觉一致性。产品采用柔和蓝白原创插画、圆角文件线稿与现有Lucide操作图标。

## 决策

### 实现方案

[品牌模块](../../../../web/src/config/brand.js)拥有本地头像和插图地址；[默认头像入口](../../../../web/src/utils/pixelAvatar.js)按用户与智能体角色返回本地素材，保留原调用名称和空标识校验。自定义上传头像仍优先展示，不修改数据库内容。品牌标记、浏览器图标与全部文件类型SVG使用统一线稿，文件映射和按钮行为保留。登录图以本地插画替换CSS占位，欢迎区展示助手头像。

## 替代方案

保留随机外部头像增加网络依赖；将全部操作按钮改为插画降低小尺寸识别度，均不采用。供应商身份标志和用户上传的业务图片保留真实含义。

## 后果

默认头像不再向第三方传递标识。智能体按ID散列稳定分配九款本地头像，相同ID在各入口保持一致，池内允许重复；不同用户共享同一默认插画，姓名文字负责区分；上传自定义头像的能力保留。文件图标使用大号MD、HTML、PDF等类型字母和专属符号，交付卡片的图标为28像素，继续保留后缀文字。基础三张JPEG约60KB，新增九款头像约135KB，不新增依赖。未使用的旧图片保留在仓库，未作为新版页面素材使用。

## 验证

SVG XML解析和diff空白检查通过。前端lint通过；全量unit初次仅会话统计的旧默认头像源码断言失败，其余通过。角色断言已显式更新，相关10项unit及生产构建通过，构建保留既有大chunk提示；独立只读审查无阻断问题。补充验证：头像分配unit、lint及生产构建通过；SVG可解析。真实浏览器截图确认智能体列表已出现不同头像。文件列表、深浅色和响应式未完成实页验证，不视为通过。

## 素材来源

使用内置image_gen生成原创插画；品牌与文件图标使用源码SVG。生成提示词：助手头像依据已确认概念稿，短深色头发、蓝衬衫、温和表情、浅蓝圆形背景、适配32像素；用户头像为同风格齐肩深色头发与蓝衬衫；登录插图为三份白色文件、蓝色连接带与纸飞机，留白、柔和纹理、无文字。新增头像由九宫格素材分别打包为本地256像素JPEG，提示词要求九个不同发型、眼镜与年龄特征，蓝衬衫、浅蓝背景、简化卡通线条和一致柔和质感。素材属于链证出海原创方案，未使用豆包的品牌标识或角色。
