# 出海预审1.2的结构化展示与固定模板

状态：implemented
类型：feature
Owner：competition/core-skill-v1.2/export-document-review/scripts/render_review.py

## 问题

预审看板的摘要与证据详情使用长文本，阅读者难以辨认事实、行动与复核条件。

## 决策

### 实现方案

在competition/core-skill-v1.2交付独立1.2.0包，保留1.1版本。result.json的基础事实、状态与版本规则保持原约定；可选展示字段提供短摘要卡片、行动卡片、事项要点和证据摘要。渲染脚本校验长度、关联ID及卡片语义色；固定模板按纯文本渲染，准确原文可展开，重要限制直接可见。旧记录缺少展示字段时保留原字段，不自动按标点推断事实。

## 替代方案

只改系统提示词不能改变固定HTML布局；让模型自由生成HTML会分散结构、计数与交互的事实来源。

## 后果

新智能体需要上传完整ZIP、选择实际新版slug并预加载，单独复制系统提示词。展示摘要准确性仍依赖模型和人工核查，脚本不验证法规或事实。旧看板不会自动更新；按钮仅整理本地草稿和复核指令。

## 验证

包验证覆盖旧记录、引用安全、未解决事项不能关闭、版本保留，以及新增展示字段的非法类型、未知事项和错误绿色状态。模拟v1/v2用于浏览器交互验证，不能替代真实模型核查测试。
