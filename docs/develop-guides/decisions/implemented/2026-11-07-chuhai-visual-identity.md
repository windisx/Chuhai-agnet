# 链证出海展示层品牌与视觉统一

状态：implemented
类型：feature
Owner：web/src/config/brand.js

## 问题

通用平台的旧品牌、推广入口和不统一的文字层次影响竞赛产品展示。产品要求保留已跑通的对话预审流程，仅美化现有首页、登录、导航与对话界面。

## 决策

### 实现方案

[前端品牌模块](../../../../web/src/config/brand.js)拥有固定的竞赛展示品牌，主页、登录和导航使用同一标识。后端品牌配置、协议地址、认证、初始化和OIDC逻辑保持原义，不改写用户数据、历史消息、Run请求及存储键。

全局配色和字体沿用[基础变量](../../../../web/src/assets/css/base.css)及[深色变量](../../../../web/src/assets/css/base.dark.css)；Ant Design主题与之对应。主页与登录装饰使用本地SVG/CSS，不新增运行依赖或外部资源请求。导航、Markdown正文、输入框和交付物卡片的样式由原组件维护，保留原事件和选择项。

移除原项目推广、专属Star请求及外部文档入口，保留功能资源的真实来源、协议字段和仓库许可证。知识库内部类型仍为milvus，展示标签为“本地知识库”；第三方类型标签不变。

## 替代方案

- 新建任务工作台、强制表单和结果侧栏改变用户已验证的流程，增加接口开发，不采用。
- 仅替换Logo不能统一阅读体验；全部重写组件会扩大回归范围，均不采用。

## 后果

产品具有固定前端品牌；服务端返回旧品牌不会覆盖这些展示入口。业务操作沿用现有界面，不增加自动复核、自动提交等能力。已有交付HTML和用户内容保留自己的样式与文本，不由全局主题改写。新视觉素材不依赖外部下载。
