# 新版看板浏览器验证

对象：preview/demo-interface-only下人工模拟的界面数据，不是用户真实预审结果。未调用模型，未安装新版Skill，未改应用源码或实例配置。

已在本机浏览器实际操作验证：

- 首屏显示四张数量卡、短摘要、三条优先动作和紧凑事项表，无原始英文字段名堆叠。
- 点击“优先处理”：从8条演示事项筛选到3条未复核P1。
- 勾选当前筛选的全部事项：选中3条，补件草稿按3个对象组显示。
- 点击复制：页面显示已复制成功。
- 点击事项“查看证据”：侧栏展示文件名、模拟原文、定位、下一步与补件要求。
- 点击“准备本项复核”：生成带原ID和来源说明的可编辑指令，没有直接改变事项状态。
- 搜索不存在的词：显示0/8及空结果提示。
- 文件页：能看到登记的原稿和修订稿，以及未挂规则依据的范围说明。
- v2复核变化页：显示C001前后状态和内部修订依据，其他待确认数量维持。
- v1与v2页面文件分别存在；截图保存为看板预览.png。

未验证：用户实际Agent运行时的补件理解、真实文件证据判断、当前应用内嵌预览的剪贴板/下载权限、移动设备布局和自动发起AI复核。最后一项本次未实现，需后续应用接口开发。HTML离线文件已生成，可在浏览器直接打开。

Skill结构与模板校验结果另见本地验证记录.md。界面可用不代表法律核查已通过。
