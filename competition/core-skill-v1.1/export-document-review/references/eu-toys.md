# 欧盟玩具场景配置（演示范围，不是法规原文）

仅在产品确为玩具、目标市场在欧盟时使用。目标国、预期上市日期、产品年龄定位、企业角色、是否带电/含特殊材料会影响范围；无法确认时不要静默套用。

优先从当前挂载知识库实际获取：
- Toy Safety Directive 2009/48/EC：核实适用版本和时间，按本次核查需要读取原文条款及附件。
- 官方解释指南、技术文件指南：分别记录版本、发布机构和非约束性；指南不能取代法规。
- 其他可能相关的规则：只有取得原文并确认产品、时间、角色适用后才纳入；缺原文列入范围缺口，不声称已经覆盖。

检查方向：声明、测试报告、材料资料及内部文案的产品身份链；多型号报告具体测试段落和测试点的归属；文件里的标识与追溯信息；语言和角色；技术文件资料范围。是否有义务、可否以包装或随附文件满足等，均由实际规则和证据决定，不能从这份配置直接下结论。

注意：
- EN71报告整体Pass不代表所有型号/所有材料/全部文件均已满足要求。
- 内部草稿与公开供应商资料冲突时，问题归属内部草稿，不归因真实厂商。
- 公开样品资料的占位批次不是实际订单记录。日期先后关系只构成待确认线索，不能自动推定声明无效或报告伪造。
- 法规的公布、生效和适用日期可能不同。未来要求不能直接套到本次目标日期。未取得可靠依据，不宣称“规则已更新”或“当前全部合规”。
